# Nexy Corp — Site Institucional

Site institucional da **Nexy Corp**, agência de branding e criação digital. Tema espacial/cósmico em tons de roxo.

> *"Sua marca pode mais — e o digital é só o começo."*

## 📄 Seções

- **Nossa Jornada** e missão (indicadores: marcas atendidas, anos de mercado, satisfação)
- **Nossos Serviços**: sites profissionais, consultoria de branding, identidade visual, social media, web design e manual de marca
- **Fundador & CEO** (Marco Júnior) e **Nossa Equipe**
- **Alguns dos Nossos Trabalhos** (portfólio com imagens de projetos)
- **O Que Dizem Sobre Nós** (depoimentos)
- Blog, contato e chamada "Inovar Agora!"

## 🗂️ Estrutura

```
├── index.html
├── style.css
├── script.js
└── img/          # logo, fotos da equipe e capturas de projetos
```

## 🛠️ Tecnologias

HTML · CSS · JavaScript

## 🚀 Como usar

Abra `index.html` no navegador ou publique em um serviço de hospedagem estática.
